Veille de l'écosystème

Prototype · données réelles collectées le 25 octobre 2026 · rien n'est publié sur rsn.quebec

Les événements, appels et actualités en santé numérique au Québec qui se passent ailleurs qu'au RSN : partenaires, réseaux thématiques du FRQ, IVADO, Obvia, Mila, universités et organismes publics, rassemblés automatiquement à partir de leurs flux.

Proposer un événement ou une nouvelle

Votre proposition entre dans la file d'approbation de l'équipe du RSN. Elle sera publiée ici et, si elle s'y prête, reprise dans l'infolettre.

Dans le prototype, la proposition reste dans cette page ; dans la version réelle elle irait dans Notion.

File d'approbation

Ce que la collecte a trouvé sans pouvoir le publier d'office : événements des sources numériques sans mot-clé santé, nouvelles de sources santé sans mot-clé numérique, propositions reçues. Un clic publie, un clic écarte. Les éléments publiés gardent un bouton Retirer.

Appels en cours

Appels à projets, concours et appels de candidatures repérés dans les flux du FRQ, du CRM, du RSN, de CARES et des Prix Hippocrate. La date limite est extraite du texte quand elle y figure.

Actualités de l'écosystème

Radar pour l'équipe : nouvelles des organismes de l'écosystème repérées dans leurs flux. Rien n'est publié sur le site ; « Garder pour l'infolettre » met la nouvelle dans le bloc à copier pour Mailchimp.
